# AutoLoc — Plateforme de gestion de location de véhicules

## Description du Projet
Plateforme de gestion de location de véhicules multi-agences développée avec Spring Boot et Angular/JavaFX.

## Acteurs du Système
- **Client :** Parcourt le catalogue, réserve des véhicules, consulte l'historique et gère son profil.
- **Agent d'agence :** Effectue les remises/retours de véhicules, vérifie l'état des véhicules et valide les contrats localement.
- **Responsable d'agence (Manager) :** Gère la flotte locale, analyse le chiffre d'affaires et gère le personnel de son agence.
- **Administrateur :** Supervise l'ensemble des agences, gère les accès utilisateurs et consulte les statistiques globales.

## Stack Technique
- Java 17 / Spring Boot 3.x
- MySQL 8.x
- Git / GitHub
- Postman
